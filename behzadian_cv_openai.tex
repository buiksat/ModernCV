\section{Profile}
RL researcher (Ph.D.) working on policy improvement with imperfect evaluators and verifier feedback, including finite-depth error bounds for recurrent value evaluators (UPI-TRM) and robust MDPs under model uncertainty. At Meta, I build correctness and monitoring systems for large-scale online experimentation over ranking models, detecting stale, biased, or inconsistent signals. Interested in RL post-training for reasoning and long-horizon agents, including durable memory and reliable tool-use and search decisions under uncertainty.

%------------------------------------------------------------
\section{Selected Research}

\cvitem{}{%
UPI-TRM: Policy Improvement under Truncated Evaluators with Verifier-Style Rewards\newline
\emph{ICLR 2026 Workshop on AI with Recursive Self-Improvement}\newline
Co-developed finite-depth error bounds for recurrent value evaluators used in policy improvement without assuming the recurrence converges. The analysis separates endpoint discrepancy from Bellman-residual error and links centered advantage error to conservative policy-improvement bounds. Evaluated the analysis on an exact finite MDP and a fixed set of Sudoku states.
}

\cvitem{}{%
Robust and Risk-Sensitive Markov Decision Processes\newline
\emph{NeurIPS 2021 and AISTATS 2021}\newline
Developed scalable algorithms for \(L_\infty\)-constrained S-rectangular robust MDPs and percentile criteria under model uncertainty.
}
